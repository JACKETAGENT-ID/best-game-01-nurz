**Prism Leap** is an original 2D puzzle-platformer for the
[make.fun best-game-01 bounty](https://make.fun/bounty/best-game-01).
You are a little light-prism hopping through 10 hand-built levels:
flip gravity to walk on the ceiling, switch your colour to pass
matching gates, dodge spikes, bounce on springs and collect every
shard before the exit portal opens the next level.

- **Move:** ← → or A / D · **Jump:** ↑ / W / Space
- **Flip gravity:** G or Shift · **Switch colour:** C or 1 / 2 / 3
- **Restart level:** R · **Pause:** P · **Mute:** M
- 10 levels, coins, 3 lives, timer, start / win / game-over screens
- Pure static files under `game/` — no network, no build step

Serve it locally with any static server, e.g.
`python3 -m http.server` inside `game/`, then open `index.html`.
